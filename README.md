# Oracle Odyssey — From Bits to Cloud

Interactive training game. Levels 01–05 teach how a keystroke becomes binary, then how a PC boots. **Level 06 — The Instance** is the next room: you are a SQL statement walking Listener → CPU → SGA → buffer cache → storage → redo.

## Levels

1. Keyboard → CPU → Display
2. Improved Keyboard & Monitor
3. Key Press → Signal → Binary → Character
4. Full PC Boot: HD → RAM → OS
5. Binary Through Logic Gates
6. **The Instance** — walk a SQL statement through an Oracle instance

Press `1`–`6` on the menu, or click a row. `Esc` returns to the menu.

## Run

Open `index.html` in a browser (Phaser 3 is loaded from a CDN), or use any static server in this folder.
